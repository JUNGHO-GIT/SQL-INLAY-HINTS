# Architecture — SQL-Inlay-Hints

## Project Overview

**SQL-Inlay-Hints** is a VS Code extension that provides inlay hints for SQL INSERT statements in `.sql` and `.xml` (MyBatis mapper) files. It displays column names inline before each value in INSERT statements, improving code readability.

## Architecture Pattern

### Parser-Provider Pattern

The extension follows a **Parser-Provider** architecture:

1. **Parser** (`src/rules/Parser.ts`)
   - Extracts column names from SQL INSERT statements
   - Parses both `INSERT VALUES` and `INSERT SELECT` patterns
   - Handles multi-row inserts and nested structures

2. **Provider** (`src/rules/Provider.ts`)
   - Implements VS Code's `InlayHintsProvider` interface
   - Creates `vscode.InlayHint` objects for each column-value mapping
   - Positions hints inline before each value

3. **Extension** (`src/extension.ts`)
   - Entry point for activation/deactivation
   - Registers providers for SQL and XML languages
   - Manages extension lifecycle

### Data Flow

```
User opens SQL file
       ↓
VS Code activates extension (extension.ts)
       ↓
Extension registers InlayHintsProvider
       ↓
User edits document
       ↓
VS Code calls provideInlayHints()
       ↓
Parser extracts column-value mappings
       ↓
Provider creates InlayHint objects
       ↓
VS Code renders hints inline
```

### Supported SQL Patterns

| Pattern | Example | Regex |
|---------|---------|-------|
| INSERT VALUES | `INSERT INTO users (id, name) VALUES (1, 'John')` | `INSERT INTO table (cols) VALUES (vals)` |
| INSERT SELECT | `INSERT INTO backup (id) SELECT id FROM users` | `INSERT INTO table (cols) SELECT cols FROM` |
| Multi-row | `INSERT INTO users (id) VALUES (1), (2), (3)` | Multiple VALUES groups |

## Configuration

Extension provides the following user settings:

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `SQL-Inlay-Hints.enableSql` | boolean | true | Enable hints for .sql files |
| `SQL-Inlay-Hints.enableXml` | boolean | true | Enable hints for .xml files |
| `SQL-Inlay-Hints.enableKeywordHighlight` | boolean | true | Enable SQL keyword highlighting |
| `SQL-Inlay-Hints.commentColor` | string | #ffff00 | Color for query comments |
| `SQL-Inlay-Hints.stringColor` | string | #f4d4ae | Color for string literals |
| `SQL-Inlay-Hints.numberColor` | string | #00FF00 | Color for numeric literals |
| `SQL-Inlay-Hints.logLevel` | string | info | Log level (off/debug/info/warn/error) |
